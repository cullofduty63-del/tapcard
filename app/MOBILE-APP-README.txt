LumoCard mobile setup
=====================

Changes in the website:
- Removed login/register links from the main landing page.
- Added a separate /app-access page with “I have an account / Login” and “Register”.
- Added a mobile install section and PWA metadata for Android install and iPhone Add to Home Screen.
- iPhone users can use Safari > Share > Add to Home Screen to install the website as a web app.

Android wrapper source:
- android-app/ is an Android Studio project using a WebView to open https://lumocard.ir.
- It opens the same live site and keeps login/register inside the app via /app-access.
- Open android-app in Android Studio, allow Gradle sync, then Build > Build Bundle(s) / APK(s) > Build APK(s).
- The APK will be generated by Android Studio; sign it for distribution before uploading it to public downloads.

Important:
- No compiled APK is included in this archive. This environment does not have the Android SDK/Gradle build setup, so it cannot honestly provide a tested APK binary yet.
- Do not create a fake APK download link. After Android Studio creates the APK, put the signed file at public/downloads/lumocard.apk and wire the website download button to /downloads/lumocard.apk.
- The live website changes only after the updated project is deployed to Cloudflare.
